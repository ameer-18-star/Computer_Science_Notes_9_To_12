> **Answer:** A programming language is a set of rules and symbols that allows humans to write instructions for a computer to understand and execute. We need programming languages because computers only understand machine code (0s and 1s), and programming languages act as a bridge — translating human-readable instructions into commands the computer can carry out.

---

**Q3.** What is a Python interpreter?

**Q8.** What is syntax in Python?

> **Answer:** Syntax refers to the set of rules that define how Python code must be written so that the Python interpreter can understand it. Just as grammar rules govern how sentences are structured in English, Python's syntax rules govern how instructions must be structured in code. Breaking syntax rules produces an error.

---

**Q9.** What does the `print()` function do? Give an example.

> **Answer:** The `print()` function displays one or more values on the screen (in the output area). For example:
> ```python
> print("Hello, students!")
> ```
> This will display: `Hello, students!`

---

**Q10.** What is a comment in Python? Why are comments used?

> **Answer:** A comment is a line (or part of a line) in Python code that the interpreter completely ignores and does not execute. Comments are used to leave explanations, notes, or reminders inside the code for human readers — making programs easier to understand and maintain.

---

**Q11.** How do you write a single-line comment in Python? Give an example.

> **Answer:** Indentation refers to the spaces placed at the beginning of a line. ---

**Q13.** What is the difference between a syntax error and a logical error?

## Section 3: Variables and Data Types

**Q14.** What is a variable in Python? Give an example.

> **Answer:** A variable is a named container in the computer's memory that stores a value. The value can be changed at any time during the program's execution. For example:
> ```python
> age = 16
> print(age)   # Output: 16

**Q15.** Why is it called a "variable" and not a "constant"?

> **Answer:** It is called a variable because its value can vary (change) throughout the program. A constant, by contrast, holds a fixed value that never changes. Since Python allows you to reassign a new value to any variable at any point, the name "variable" reflects this flexibility.

---

**Q16.** What is the assignment operator? How is it different from the equality operator?

> **Answer:** The assignment operator `=` stores a value inside a variable — for example, `x = 10` stores the number 10 in `x`. The equality operator `==` compares two values and returns `True` or `False` — for example, `x == 10` asks "is x equal to 10?" They look similar but perform completely different actions.

---

**Q17.** List three rules for naming variables in Python.

> **Answer:**
> 1. A variable name must start with a letter (a–z, A–Z) or an underscore `_` — not a digit.
> 2. Variable names can only contain letters, digits, and underscores — no spaces or special characters like `-` or `@`.
> 3. Variable names are case-sensitive — `age`, `Age`, and `AGE` are three different variables.

---

Words like `if`, `while`, `for`, and `True` already mean something specific to Python. If you tried to use them as variable names, Python would become confused about whether you meant the keyword or the variable.

## Section 4: Arithmetic Operators

**Q27.** What are arithmetic operators? List all seven with their symbols.

> **Answer:** Arithmetic operators perform mathematical calculations. The seven arithmetic operators in Python are:
> - `+` Addition
> - `-` Subtraction
> - `*` Multiplication
> - `/` Division (returns float)
> - `//` Floor Division (discards decimal)
> - `%` Modulus (returns remainder)
> - `**` Exponentiation (power)

---

**Q28.** What is the difference between `/` and `//` in Python?

> **Answer:** The `/` operator performs true division and always returns a float, even if the result is a whole number — for example, `10 / 2` returns `5.0`. The `//` operator performs floor division and discards the decimal part, returning only the whole number — for example, `10 // 3` returns `3`, not `3.33`.

---

**Q29.** What is the modulus operator? Give a real-world use case.

> **Answer:** The modulus operator `%` returns the remainder after dividing two numbers. For example, `11 % 4 = 3` because 11 divided by 4 gives 2 with a remainder of 3. A real-world use case is checking whether a number is even or odd: if `number % 2 == 0`, the number is even; otherwise it is odd.

---

**Q30.** What does the `**` operator do? Give an example.

> **Answer:** The `**` operator raises the left number to the power of the right number (exponentiation). For example, `2 ** 8` means 2 raised to the power of 8, which equals 256. It is equivalent to multiplying 2 by itself 8 times.

---

**Q31.** What will the following code output? Explain why.
```python
print(7 / 2)
print(7 // 2)
print(7 % 2)
```

> **Answer:**
> - `7 / 2` → `3.5` (true division, returns float)
> - `7 // 2` → `3` (floor division, drops the decimal)
> - `7 % 2` → `1` (remainder: 7 = 2×3 + 1)

## Section 5: Comparison Operators

**Q32.** What are comparison operators? What do they always return?

> **Answer:** Comparison operators compare two values and determine the relationship between them — such as whether they are equal, or which one is larger. They always return a Boolean value: either `True` or `False`. The six comparison operators are: `==`, `!=`, `>`, `<`, `>=`, and `<=`.

---

**Q33.** What is the purpose of the `!=` operator? Give an example.

> **Answer:** The `!=` operator checks whether two values are NOT equal. If they are different, it returns `True`; if they are the same, it returns `False`. For example: `print(10 != 5)` outputs `True` because 10 and 5 are different.

---

**Q34.** What is the difference between `>` and `>=` operators?

> **Answer:** The `>` (greater than) operator returns `True` only if the left value is strictly larger than the right — for example, `10 > 10` is `False`. The `>=` (greater than or equal to) operator returns `True` if the left value is larger OR equal — for example, `10 >= 10` is `True`.

---

**Q35.** Write a Python expression that checks whether a student's score of 45 is a passing grade (pass mark is 40).

> **Answer:**
> ```python
> score = 45
> is_passing = score >= 40
> print("Did the student pass?", is_passing)
> # Output: Did the student pass? True
> ```

---

**Q36.** Why is it a common mistake to write `=` instead of `==` in a comparison?

> **Answer:** Because both operators use the equals sign, beginners often confuse them. `=` is the assignment operator — it stores a value (e.g., `x = 5` puts 5 into x). `==` is the comparison operator — it asks a question (e.g., `x == 5` asks "is x equal to 5?"). Using `=` where `==` is needed will cause an error or unexpected behaviour.

## Section 6: Assignment Operators

**Q37.** What are compound assignment operators? Give two examples.

> **Answer:** Compound assignment operators combine a mathematical operation with the assignment operator in one step. Instead of writing `a = a + 5`, you can write `a += 5`. Two examples:
> - `a += 10` means `a = a + 10`
> - `a *= 3` means `a = a * 3`

---

**Q38.** If `score = 50`, what is the value of `score` after `score += 15`?

> **Answer:** The value of `score` becomes `65`. The `+=` operator adds 15 to the current value of `score` (which is 50) and stores the result (65) back into `score`.

---

**Q39.** What is the output of the following code?
```python
a = 10
a *= 2
a -= 3
print(a)
```

> **Answer:** The output is `17`.
> - `a = 10`
> - `a *= 2` → `a = 10 * 2 = 20`
> - `a -= 3` → `a = 20 - 3 = 17`

---

**Q40.** What does `a **= 3` mean?

> **Answer:** It means raise `a` to the power of 3 and store the result back in `a`. It is equivalent to writing `a = a ** 3`. For example, if `a = 2`, then after `a **= 3`, the value of `a` becomes `8` (because 2³ = 8).

## Section 7: Logical Operators

**Q41.** What are logical operators in Python? Name all three.

> **Answer:** Logical operators are used to combine two or more Boolean (True/False) conditions into one final True/False result. The three logical operators in Python are:
> - `and` — True only if BOTH conditions are True
> - `or` — True if at least ONE condition is True
> - `not` — Reverses (flips) a Boolean value

---

**Q42.** Explain the `and` operator with an example.

> **Answer:** The `and` operator returns `True` only when both conditions on either side of it are True. If even one side is False, the result is False. For example:
> ```python
> score = 85
> attendance = 80
> eligible = (score >= 80) and (attendance > 75)
> print(eligible)   # True — both conditions are True
> ```

---

**Q43.** Explain the `or` operator with an example.

> **Answer:** The `or` operator returns `True` when at least one of the two conditions is True. It only returns `False` when both conditions are False. For example:
> ```python
> is_friday = False
> is_prefect = True
> gets_reward = is_friday or is_prefect
> print(gets_reward)   # True — because is_prefect is True
> ```

---

**Q44.** Explain the `not` operator with an example.

> **Answer:** The `not` operator flips a Boolean value — it turns `True` into `False` and `False` into `True`. For example:
> ```python
> x = True
> print(not x)    # False
> y = False
> print(not y)    # True
> ```

---

**Q45.** What is the output of the following code?
```python
a = True
b = False
print(a and b)
print(a or b)
print(not a)
```

> **Answer:**
> - `a and b` → `False` (both must be True; b is False)
> - `a or b` → `True` (at least one is True; a is True)
> - `not a` → `False` (flips True to False)

---

**Q46.** When does `False or False` evaluate to True?

> **Answer:** It never does. `False or False` always evaluates to `False`. The `or` operator returns `True` only when at least one operand is `True`. Since both operands here are `False`, the result is `False`.

---

**Q47.** Create a real-life scenario where the `and` operator would be useful in a Python program.

> **Answer:** A login system could use `and` to verify both a username and password: a user is granted access only if the username is correct AND the password is correct. If either one is wrong, access is denied. In Python: `access = (username == "admin") and (password == "12345")`.

## Section 8: Operator Precedence

**Q48.** What is operator precedence in Python?

> **Answer:** Operator precedence is the set of rules that determines which operator Python evaluates first when an expression contains multiple operators. Just like in mathematics where multiplication is done before addition, Python follows a strict order: Parentheses first, then Exponentiation, then Multiplication/Division/Modulus, then Addition/Subtraction.

---

**Q49.** What is the correct order of operator precedence in Python (from highest to lowest)?

> **Answer:** The order from highest to lowest precedence is:
> 1. `( )` — Parentheses
> 2. `**` — Exponentiation
> 3. `*`, `/`, `//`, `%` — Multiplication, Division, Floor Division, Modulus
> 4. `+`, `-` — Addition and Subtraction

---

**Q50.** Why does `2 + 3 * 4` give 14 and not 20?

> **Answer:** Because multiplication has higher precedence than addition. Python evaluates `3 * 4 = 12` first, then adds 2 to get `14`. To get 20, you would need to use parentheses: `(2 + 3) * 4`, which forces the addition to happen first.

---

**Q51.** How do parentheses affect operator precedence?

> **Answer:** Parentheses have the highest precedence of all — whatever is inside parentheses is always evaluated first, regardless of the other operators present. This lets programmers override the default order and control exactly which calculation happens first. For example, `(2 + 3) * 4 = 20` vs `2 + 3 * 4 = 14`.

---

**Q52.** Evaluate step by step: `4 + 10 / 2 - 11 % 3`

> **Answer:**
> - Step 1: Division → `10 / 2 = 5.0`
> - Step 2: Modulus → `11 % 3 = 2`
> - Step 3: Addition → `4 + 5.0 = 9.0`
> - Step 4: Subtraction → `9.0 - 2 = 7.0`
> - **Final answer: 7.0**

---

**Q53.** What is an f-string in Python?

> **Answer:** An f-string (formatted string) is a string prefixed with the letter `f` that allows you to embed variables or expressions directly inside the string using curly braces `{}`. Python automatically evaluates whatever is inside the braces and inserts the result. For example: `f"The answer is {2 + 3}"` produces the string `"The answer is 5"`.

---

**Q54.** What is meant by saying that `**` is "right-associative"?

> **Answer:** Right-associative means that when multiple `**` operators appear in a row, Python evaluates them from right to left. For example, `2 ** 3 ** 2` is calculated as `2 ** (3 ** 2)` = `2 ** 9` = `512` — not as `(2 ** 3) ** 2` = `64`. This matches standard mathematical convention for exponentiation.

---

**Q55.** What is the output of `print(3 + 2 ** 2 * 5)`? Show your working.

> **Answer:**
> - Step 1: Exponentiation → `2 ** 2 = 4`
> - Step 2: Multiplication → `4 * 5 = 20`
> - Step 3: Addition → `3 + 20 = 23`
> - **Output: 23**

**Q57.** Explain the difference between `print("5 + 3")` and `print(5 + 3)`.

> **Answer:** `print("5 + 3")` treats `5 + 3` as a string (text) and prints it exactly as written: `5 + 3`. The quotation marks tell Python this is just characters, not a calculation. `print(5 + 3)` treats `5 + 3` as an arithmetic expression, evaluates it, and prints the result: `8`.

> **Answer:** Comments help anyone reading the code — including the programmer themselves in the future — understand what the code is doing and why.
